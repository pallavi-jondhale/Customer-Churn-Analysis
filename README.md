# Customer Churn Analysis - Power BI

## About the Project

This project is a Customer Churn Analysis Dashboard made in Power BI.
It helps to understand:
- How many customers left
- How many customers stayed
- Which customers are more likely to leave
- Which contract type has more churn
- How churn changes with customer tenure
## Key Numbers

- Total Customers: 7,043
- Churned Customers: 1,869
- Churn Rate: 26.54%
- Retained Customers: 73%

## Dashboard Shows
- Total Customers
- Churn Rate
- Churned Customers
- Customer Retention
- Churn by Contract
- Churn by Tenure
- Monthly Charges
- Customer Risk

## Key Insights
- Month-to-Month customers have more churn.
- New customers are more likely to leave.
- High-risk customers need more attention.
- Customer tenure and contract type affect churn.
